# Rezumi 🚀

AI-powered resume builder and analyzer built with MERN stack + Groq AI.

## Live Demo
🌐 https://rezumi-peach.vercel.app

## Features
- 🔨 Build resume from form or plain text (AI enhanced)
- 🔍 Analyze resume vs job description (AI match score)
- 📄 Export as PDF and DOCX
- 🔐 JWT Authentication

## Tech Stack
- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- AI: Groq API (LLaMA 3.1)
- Deployment: Vercel + Render
